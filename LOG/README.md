# LOG-Verzeichnis

In diesem Ordner werden automatisch Log-Dateien erstellt beim Start der Anwendung.

## Log-Dateien
- Format: `app_YYYY-MM-DD.log`
- Beispiel: `app_2026-08-14.log`

## Log-Level
- `[DEBUG]` - Detaillierte Debug-Informationen
- `[INFO]` - Allgemeine Informationen
- `[WARNING]` - Warnungen
- `[ERROR]` - Fehler mit Stack-Trace

## Beispiel-Log-Eintrag
```
[2026-08-14 10:30:15.123] [INFO   ] === Betriebsmittel Publisher gestartet ===
[2026-08-14 10:30:15.124] [INFO   ] Version: 1.0.0
[2026-08-14 10:30:15.125] [INFO   ] Lade JetBrains Mono Font...
[2026-08-14 10:30:15.130] [INFO   ] JetBrains Mono erfolgreich geladen
```
